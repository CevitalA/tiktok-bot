# دليل تشغيل بوت تليجرام مع تطبيق الليجات (Telegram Mini App) 🏆

مشروع متكامل يربط بين **بوت تليجرام بنظام اشتراكات** و**تطبيق ويب تفاعلي (Telegram WebApp / Mini App)** لفرز وعرض دوريات تيك توك لايف (من A1 حتى D5)، مع إمكانية حصرية للأدمن لرفع وتحديث ملف الإكسل (`.xlsx`) لتحديث البيانات لجميع المشتركين فوراً.

---

## 📁 هيكل المشروع

```text
telegram_league_bot/
├── bot.py             # كود بوت التليجرام (نظام الاشتراكات + رفع الإكسل + الأوامر)
├── server.py          # سيرفر FastAPI (تقديم الـ Mini App + التحقق الأمني من الجلسة)
├── run.py             # تشغيل السيرفر والبوت معاً بأمر واحد
├── database.py        # إدارة المشتركين، الصلاحيات، وتوليد أكواد التفعيل
├── excel_parser.py    # قراءة ومعالجة ملف الإكسل وفرز الحسابات حسب الـ 20 ليج
├── static/
│   └── index.html     # واجهة تطبيق الويب التفاعلي (React Mini App)
├── data/
│   ├── bot_database.json   # قاعدة بيانات المشتركين والأكواد
│   └── leagues_data.json   # بيانات الحسابات المحدثة من الإكسل
├── .env.example       # نموذج إعدادات البيئة والتوكن
└── requirements.txt   # المكتبات المطلوبة
```

---

## ⚡ خطوة 1: تجهيز البوت على تليجرام

1. افتح تطبيق تليجرام وتحدث مع البوت الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل الأمر `/newbot`، ثم اختر اسماً للبوت ويوزراً ينتهي بكلمة `bot` (مثال: `TikTokLeagues_bot`).
3. انسخ الـ **API Token** الذي يعطيه لك (مثال: `7123456789:AAH...`).
4. **تفعيل زر التطبيق داخل المحادثة (Menu Button):**
   - في `@BotFather`، أرسل `/mybots` واختر بوتك.
   - اضغط **Bot Settings** ثم **Menu Button** ثم **Configure menu button**.
   - أرسل الرابط الخاص بموقعك (يجب أن يبدأ بـ `https://`).
   - اكتب النص الظاهر على الزر: `🏆 تصفح الليجات`.

## ⚙️ خطوة 2: تثبيت الإعدادات والتشغيل

### 1. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

### 2. ضبط ملف الإعدادات `.env`:
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
وقم بتعديل القيم:
- `BOT_TOKEN`: التوكن الذي حصلت عليه من `@BotFather`.
- `ADMIN_IDS`: معرف التليجرام الخاص بك (يمكنك معرفته بمراسلة بوت `@userinfobot`).
- `ADMIN_USERNAME`: اسم المستخدم الخاص بك (بدون `@`) ليتواصل معك المشتركون.
- `WEBAPP_URL`: رابط السيرفر (مثلاً: `https://yourdomain.com`).

### 3. تشغيل المشروع:
```bash
python run.py
```
سيقوم هذا الأمر بتشغيل:
1. سيرفر الويب FastAPI على المنفذ `8000`.
2. بوت التليجرام ليبدأ في استقبال الرسائل والملفات.

## 👑 مميزات الأدمن وطريقة رفع ملف الإكسل

### 1. رفع ملف الإكسل عبر المحادثة مباشرة (الأسهل والأسرع):
- يدخل الأدمن إلى محادثة البوت الخاصة.
- يقوم بسحب وإسقاط ملف الإكسل (`.xlsx` أو `.xls`) أو إرساله كملف (Document).
- يقوم البوت تلقائياً بما يلي:
  1. التحقق من هوية المرسل أنه الأدمن.
  2. قراءة أعمدة الملف بذكاء (سواء كانت العناوين بالعربي أو الإنجليزي: `Rank`, `Creator Name`, `Username`, `League`, `Est Earnings`, `Diamonds`, `Eligibility`).
  3. فرز وتنظيم الحسابات في الـ 20 ليج (من A1 حتى D5).
  4. حفظ التحديث على السيرفر، وتحديث التطبيق لجميع المشتركين في نفس اللحظة!
  5. إرسال تقرير فوري بالأرقام (إجمالي الحسابات، الأرباح، الألماس).

### 2. أوامر تحكم الأدمن في المشتركين:
- `/admin` : عرض إحصائيات النظام (المشتركين النشطين، الحسابات المسجلة، تاريخ آخر ملف).
- `/addsub <user_id> <days>` : تفعيل اشتراك لمستخدم مباشرة (مثال: `/addsub 123456789 30`).
- `/delsub <user_id>` : إيقاف أو إلغاء اشتراك مستخدم.
- `/gencode <days> [count]` : توليد أكواد تفعيل وتوزيعها أو بيعها للمشتركين (مثال: `/gencode 30 5`).
- `/broadcast <رسالتك>` : إرسال رسالة جماعية لجميع المشتركين المسجلين.
- `/export` : تحميل ملف البيانات المصنف الحالي بصيغة JSON.

## 🔒 تجربة المشترك العادي

1. عندما يرسل المستخدم `/start`:
   - يفحص البوت حالة اشتراكه.
   - **إذا كان غير مشترك:** يعرض له رسالة ترحيب توضح أن البوت باشتراك، ويعطيه معرّفه (ID)، وزر للتواصل مع الأدمن، وزر لإدخال كود التفعيل (`/redeem <code>`).
   - **إذا كان مشتركاً مفعلاً:** يظهر له زر WebApp: `🏆 فتح تطبيق الليجات` مع إشعار بعدد الأيام المتبقية.
2. عند فتح التطبيق:
   - يتأكد السيرفر من صحة جلسة تليجرام واشتراك المستخدم.
   - يفتح التطبيق مباشرة مع كافة الليجات والحسابات المحدثة!

## 🌐 النشر على الإنترنت (VPS / Cloud)

شرط تليجرام الوحيد لـ WebApp هو أن يكون الرابط **HTTPS**. يمكنك استخدام أي من التالي:

1. **سيرفر خاص VPS (Ubuntu):**
   - استخدم Nginx + Certbot (Let's Encrypt مجاني) لربط الدومين مع المنفذ `8000`.
   - شغل المشروع كخدمة عبر `systemd` أو `pm2`.

2. **الاستضافات السحابية المجانية/السريعة:**
   - **Render.com** أو **Railway.app** أو **Koyeb**: توفر دومين HTTPS تلقائياً وبالمجان.

3. **للتجربة السريعة محلياً:**
   - يمكنك استخدام أداة **Cloudflare Tunnels** أو **ngrok**:
     ```bash
     ngrok http 8000
     ```
   - انسخ الرابط الذي ينتهي بـ `.ngrok-free.app` وضعه في `WEBAPP_URL` بملف `.env`.
